# 2D Survival

Unity 6로 제작한 모바일 2D 슈팅 로그라이트(뱀서라이크) 프로젝트입니다. 몰려오는 적을 자동 공격으로 처치하고, 경험치와 특전을 통해 성장하며 최종 웨이브까지 생존하는 게임입니다.

- 개발 기간: 4주
- 엔진: Unity `6000.0.34f1`
- 클라이언트: C#, Unity 2D, URP, UGUI
- 외부 연동: UnityWebRequest 기반 로그인·회원가입·랭킹 API
- 시연 영상: [YouTube](https://youtu.be/NIE7aal20YE)
- 게임 소개서: [2D_Survival.pdf](./2D_Survival.pdf)

## 주요 기능

- 조이스틱 기반 플레이어 이동, 체력, 피격 피드백, 아이템 자석 효과
- 일반 적 3종과 골렘 계열 보스 웨이브
- 탄막, 회전 검, 곡괭이, 오오라, 범위 폭발 무기
- 경험치, 레벨업, 17종 특전, 코인, 회복 및 자석 아이템
- 적·투사체·드롭 아이템을 위한 오브젝트 풀
- 메인, 게임, 결과 화면으로 이어지는 게임 흐름
- 로그인, 회원가입, 상위 랭킹 및 점수 전송

## 프로젝트 구조

```text
Assets/
├─ 1.Scenes/                    # Main, Game, Result 씬
├─ 2.Scripts/SurvivorsLike/
│  ├─ Content/                 # 적 스폰과 웨이브 동작
│  ├─ Controller/              # 플레이어, 적, 무기 제어
│  ├─ Effect/                  # 피격·폭발 효과
│  ├─ Interface/               # 피해, 드롭, 자석 행동 경계
│  ├─ Item/                    # 경험치와 드롭 아이템
│  ├─ Manager/                 # 게임 상태, 레벨, 오브젝트, 풀
│  ├─ UI/                      # 메인, 게임, 레벨업, 결과 UI
│  └─ Util/                    # 상수, 특전, 통신 프로토콜
└─ 6.Resources/                # 프리팹과 외부 리소스
```

빌드 씬 순서는 다음과 같습니다.

1. `Assets/1.Scenes/Main_SurvLike.unity`
2. `Assets/1.Scenes/Game_SurvLike.unity`
3. `Assets/1.Scenes/Result_SurvLike.unity`

## 실행 방법

1. Unity Hub에서 Unity `6000.0.34f1`을 설치합니다.
2. 저장소 루트를 Unity 프로젝트로 엽니다.
3. 패키지 임포트와 스크립트 컴파일이 끝날 때까지 기다립니다.
4. `Main_SurvLike` 씬을 열고 Play Mode를 실행합니다.

로그인·회원가입·랭킹은 외부 서버 상태에 영향을 받습니다. 서버를 사용할 수 없을 때의 오프라인 실행 경로는 앞으로 보완할 예정입니다.

## 현재 상태

이 저장소는 완성된 기존 프로젝트를 포트폴리오용으로 다시 정리하는 중입니다. 현재 우선순위는 콘텐츠 추가보다 다음 항목에 있습니다.

- 정확한 Unity 버전에서 실행 및 주요 흐름 재검증
- 풀링, 코루틴, 이벤트 수명주기의 명백한 오류 수정
- Excel 원본과 C# 컨버터를 이용한 특전, 드롭, 적·무기 능력치, 웨이브 데이터 전환
- 100·300·500개체 스트레스 테스트와 성능 수치 기록
- 외부 에셋의 사용 범위와 라이선스 정리

현재 설치 환경에는 Unity `6000.4.0f1`만 있어, 요구 버전인 `6000.0.34f1`에서의 실행은 아직 재검증되지 않았습니다. 생성된 C# 프로젝트의 MSBuild 검증도 해당 버전 Source Generator 부재로 중단되었으므로, 현재 상태를 빌드 성공으로 기록하지 않습니다.

## 알려진 한계

- 게임 밸런스와 리소스 경로가 코드에 다수 하드코딩되어 있습니다.
- 싱글톤, 오브젝트 이름 검색, `Resources` 경로 의존이 큽니다.
- 자동화된 Edit Mode/Play Mode 테스트가 없습니다.
- 성능 최적화 의도는 있으나 동일 조건의 측정 결과가 아직 없습니다.
- 외부 에셋 원본과 데모 파일이 많이 포함되어 있어 공개 전 라이선스 검토가 필요합니다.
