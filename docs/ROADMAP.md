# Project Roadmap

최종 갱신: 2026-07-17

이 문서는 프로젝트 작업 상태의 단일 기준이다. 상세 근거는 `TECHNICAL_REVIEW.md`, 실제 작업과 검증 결과는 `WORKLOG.md`에 기록한다.

## 상태 정의

- `예정`: 아직 시작하지 않음
- `진행 중`: 현재 작업 중이며 동시에 하나만 허용
- `보류`: 외부 환경이나 사용자 결정이 필요함
- `완료`: 완료 조건과 검증을 모두 충족함

## 현재 작업

- 현재 진행 중인 항목: 없음
- 다음 추천 항목: `P0-01` 정확한 Unity 버전에서 실행 기준선 확보

## P2: Excel 기반 데이터 파이프라인

목표 흐름은 `Excel 원본 → C# 컨버터 검증 → 결정적인 Unity용 데이터 생성 → 런타임 로드`이다. 생성 결과는 직접 수정하지 않으며, 초기에는 현재 저장소 안에서 운영한다.

| ID | 작업 | 상태 | 완료 조건 |
|---|---|---|---|
| P2-01 | 데이터 파이프라인 구조와 포맷 결정 | 예정 | Raw Excel, 스키마, 컨버터, 생성물, Unity 로더의 경로와 책임이 문서화됨 |
| P2-02 | C# 데이터 컨버터 CLI 골격 구축 | 예정 | 명령 한 번으로 변환 가능하고 성공·검증 실패·시스템 오류가 종료 코드로 구분됨 |
| P2-03 | Excel 작성 규칙과 공통 스키마 정의 | 예정 | 헤더, ID, 타입, 빈 값, enum, 참조, 범위와 수식 사용 규칙이 문서화됨 |
| P2-04 | 공통 데이터 검증기 구현 | 예정 | 중복 ID, 필수 값, 타입, enum, 범위와 잘못된 참조가 파일·시트·행·열과 함께 보고됨 |
| P2-05 | 결정적 생성과 최신 상태 검사 구현 | 예정 | 동일 입력은 바이트 단위로 같은 결과를 만들고 오래된 생성물을 검사 명령으로 탐지함 |
| P2-06 | 특전 데이터 수직 구현 | 예정 | Excel에서 특전 이름, 효과, 수치, 상한을 수정해 컨버터와 Unity 로딩까지 검증됨 |
| P2-07 | 가중치 기반 드롭 테이블 전환 | 예정 | 아이템 가중치와 레벨 조건을 Excel에서 조정하고 참조 오류를 컨버터가 차단함 |
| P2-08 | 적·무기 능력치 데이터 전환 | 예정 | 체력, 속도, 공격력, 보상과 무기 성장 수치를 Excel에서 조정할 수 있음 |
| P2-09 | 웨이브·보스 스폰 데이터 전환 | 예정 | 출현 종류, 수, 간격과 보스 구성을 Excel에서 편집할 수 있음 |
| P2-10 | Unity 자동 임포트와 생성물 보호 | 예정 | 변환 결과를 Unity가 재현 가능하게 로드하고 생성 파일에 직접 수정 금지 표시가 있음 |
| P2-11 | CI 데이터 검증 추가 | 예정 | 잘못된 Excel 또는 오래된 생성물이 제출되면 자동 검증이 실패함 |
| P2-12 | 프리팹 레지스트리와 공통 풀 항목 설계 | 예정 | 새 풀링 대상 추가 시 타입 조건문 수정이 필요하지 않음 |
| P2-13 | 신규 `Resources` 문자열 의존 제거 | 예정 | 새 데이터 경로에서 안정적인 데이터 ID와 직렬화 참조를 사용함 |
| P2-14 | 데이터 저장소 분리·서브모듈 도입 재평가 | 예정 | 독립 배포, 다중 프로젝트 공유, 권한 분리 필요성을 근거로 도입 여부를 결정함 |
